Give software a place to run, a boundary it cannot quietly cross, and an answer you can inspect.

Substrate is a standalone Linux execution service. It owns guarded workspaces, bounded processes and interactive sessions. Every mutation has a durable operation record; every advertised capability comes from a machine probe.

01 / CONFINE

A boundary with teeth

Guarded filesystem access, read-only inputs, a private network namespace, process and memory bounds, and whole-tree termination.

02 / RECORD

Durable before dispatch

An operation is recorded before effects begin. A lost connection leaves an identity to reconcile, instead of a reason to blindly repeat a command.

03 / OBSERVE

Facts, including uncertainty

Inspect exit status, captured output, resource usage and applied isolation. If execution cannot be proved, Substrate reports an unknown state or a named refusal.

SECURITY BOUNDARIES

Policy above. Enforcement below.

Callers such as Mantle decide what work to request. Substrate admits and confines it on a trusted Linux host. The host administrator, daemon and kernel remain inside the trusted boundary.

What this protects

Workspace paths cannot escape through traversal or links. Missing enforcement is a refusal. Resource bounds and observations describe the actual selected host.

What remains trusted

This is not protection from a compromised host administrator or kernel. Captured process output is durable state; applications must keep secrets and login codes out of it.
