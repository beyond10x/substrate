# Confinement contract ESS specification

The ESS domain `substrate.confinement` under `spec/confinement/` (system `substrate`, `format:
ess/32`, pinned to ESS 0.70.0), with its committed suite `spec/confinement-suite.json` and the
generated Rust enums in `crates/substrate-host/src/generated/confinement.rs`, both held to
regenerated bytes by `cargo xtask check-ess`.

It specifies atlas ADR 0109's ten contract families, the six adapters and the capability facts
each proves at open, `OpenAdapter` and `AdmitProfile`, and their named refusals; ADR 0044 records
the decision locally.

The interpreted run checks the model, not an adapter. Each adapter's lane runs the authored
scenarios named `<adapter>-*-on-<lane>`; `absent-<adapter>-*` scenarios run where the adapter is
absent. Known ESS defect: https://github.com/beyond10x/ess/issues/693.
