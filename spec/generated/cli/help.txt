Drive a Substrate daemon over its Unix socket

Usage: b10x-substrate [OPTIONS] <COMMAND>

Commands:
  events       Read one page of the daemon's event log
  exec         
  machine      Show the daemon's capability snapshot and facts
  metrics      Show the resource usage the daemon observes for an exec or a workspace
  operation    
  session      
  workspace    
  completions  Emit shell completions
  help         Print this message or the help of the given subcommand(s)

Options:
      --socket <global_state>
          

      --output <global_output>
          [default: human]
          [possible values: human, json]

  -h, --help
          Print help
